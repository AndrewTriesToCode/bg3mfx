# Spatial HDR and post-processing validation — October 11, 2026

**Archive notice:** This is dated validation evidence, not the active
implementation guide. See the [architecture](../../architecture.md) and
[validation index](../README.md) for current behavior and status. The local
trace path below is historical and may no longer exist.

The diagnostic main-menu run confirms that Spatial consumes the scene after
bloom and color grading, before BG3's FSR color-compression pass, then returns
its HDR result to BG3's existing tone-map and UI path.

## Test

BG3 4.1.1.7631656 ran on Apple M5 Pro / macOS 27.0 in a window at 1280×800.
The trace launch skipped the Larian launcher and enabled the Metal HUD. Spatial
Ultra Quality was active at the title screen/main menu, with a 984×615 input and
1280×800 output. No save or gameplay scene was loaded. The installed app bundle
was not patched.

Trace: `build/spatial-hdr-postprocess-verified-2026-10-11.jsonl` (PID 4810).

## Observed pass chain

The trace recorded these named passes before scaling:

1. `PPBloomUpsampleBlurAndCombine_PS`
2. `PPColorGradingApplyLUTPS`
3. `FSR_Tonemap`

The MetalFX Spatial input texture was the 984×615 linear-HDR source sampled by
`FSR_Tonemap`, before that pass's bounded color compression. Both native compute
dispatches, `FSR` and `FSR_RCAS`, were skipped. The trace recorded two
MetalFX encodings to a 1280×800 target and a successful GPU completion event
(status 4).

After scaling, BG3's `PPToneMap_LUT` sampled the 1280×800 MetalFX destination
and rendered a full-resolution scene target. The following UI render pass used
that scene target, confirming that BG3's native tone map and UI composition
remain downstream of Spatial.

After capturing the trace, Upscaling Type was restored to Off, Anti-Aliasing to
TAA, FidelityFX Sharpening remained enabled, the Metal HUD remained enabled,
and the display remained Windowed at 1280×800. The game exited normally (0).

This verifies pass ordering, resource dimensions, skipped native FSR/RCAS work,
and completed MetalFX encoding in the title-screen scene. It does not establish
visual parity, color accuracy across other scenes, performance, or gameplay
behavior. The user's separate quiet-runtime trial reported normal-looking color;
this diagnostic trace is not a controlled image-quality comparison.
